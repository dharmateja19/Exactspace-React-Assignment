# React Projects

A collection of React.js projects built to explore frontend development, API integration, component-based architecture, and real-time communication.

This repository contains two projects developed using React.js, JavaScript, and Tailwind CSS.

## Projects

### 1. React Real-Time Chat Application

A real-time chat application built using React, Node.js, Express, and Socket.IO.

**Features:**
- Real-time messaging between connected clients.
- Random username assignment.
- Message likes with live synchronization.
- Emoji picker.
- @Mentions with username suggestions.
- Reset chat functionality.

**Technologies:** React.js, Tailwind CSS, Node.js, Express.js, Socket.IO.

**Documentation:** [Chat Application README](./chat-app/README.md)

### 2. Photo Gallery Application

A responsive photo gallery that fetches and displays photographs using the Picsum Photos API.

**Features:**
- Fetch photographs using API pagination.
- Display images with photographer information.
- Interactive like functionality.
- Lazy loading of images.
- Load More functionality.
- Responsive gallery layout.

**Technologies:** React.js, JavaScript, Tailwind CSS, Picsum Photos API, Font Awesome.

**Documentation:** [Photo Gallery README](./photo-gallery/README.md)
